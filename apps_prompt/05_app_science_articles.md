المطلوب:
إنشاء تصميم واجهة تطبيق جوال احترافي متكامل لتطبيق علمي عربي باسم "علومكم"، متخصص في قراءة المقالات العلمية في مختلف المجالات، مع تجربة استخدام ممتازة، وهوية بصرية قوية، ونظام تصميم واضح، ومجموعة شاشات مترابطة قابلة للتحويل إلى نموذج أولي عالي الدقة.
فكرة التطبيق:
"علومكم" هو تطبيق عربي حديث يتيح للمستخدمين تصفح وقراءة المقالات العلمية الموثوقة في تخصصات متعددة مثل:
- الطب
- الأحياء
- الفيزياء
- الكيمياء
- الرياضيات
- الفضاء
- التقنية
- الهندسة
- البيئة
- العلوم الإنسانية المرتبطة بالمعرفة العلمية عند الحاجة
الجمهور المستهدف:
- طلاب الجامعات
- الباحثون
- المعلمون
- القراء المهتمون بالعلوم
- مستخدمون يحبون المحتوى المعرفي الموثوق
- فئة عمرية واسعة من 16 سنة فما فوق
الهدف من التطبيق:
- تبسيط الوصول إلى المقالات العلمية
- تقديم تجربة قراءة عربية ممتازة
- تنظيم المحتوى العلمي في واجهة جذابة وسهلة
- رفع قيمة المحتوى العلمي بصريًا
- تشجيع المستخدم على الاستكشاف والحفظ والعودة اليومية للتطبيق
المطلوب بصريًا:
أنتج واجهة Mobile App UI كاملة بأسلوب:
Modern + Premium + Clean + Scientific + Trustworthy
الهوية البصرية:
- طابع معرفي علمي راقٍ
- ألوان فخمة وهادئة توحي بالعلم والثقة والاحتراف
- اعتماد لوحة ألوان أساسية مثل:
  - Deep Navy Blue
  - Rich Dark Blue
  - Black Luxury Tone
  - White
  - Soft Cyan / Teal accents
- استخدام تباين بصري واضح
- تصميم أنيق غير طفولي وغير مبالغ في الزينة
- واجهات مريحة للعين ومناسبة للقراءة الطويلة
- دعم الوضع الليلي بشكل متكامل
اللغة والاتجاه:
- اللغة الأساسية: العربية
- اتجاه التصميم: RTL
- مع قابلية دعم اللغة الإنجليزية لاحقًا
- العناوين العربية يجب أن تكون واضحة جدًا
- النصوص منظمة، سهلة القراءة، وغير مزدحمة
الخطوط:
- اختر خطوطًا عربية حديثة وفاخرة وواضحة
- اجعل العناوين قوية والوصف أخف
- حافظ على Hierarchy بصري ممتاز بين العنوان، النص، الوسوم، وعناصر التحكم
الشاشات المطلوبة:
1. Splash Screen
- شعار أو معالجة بصرية لاسم "علومكم"
- انطباع أول قوي واحترافي
- خلفية علمية أنيقة وهادئة
2. Onboarding Screens
- 3 شاشات تعريفية
- تعريف سريع بفوائد التطبيق
- إبراز القراءة العلمية، التصنيفات، الحفظ، والاكتشاف
3. Sign In / Sign Up
- تسجيل دخول بسيط وأنيق
- دعم البريد الإلكتروني أو تسجيل اجتماعي بشكل بصري
- تصميم نظيف وحديث
4. Home Screen
- شريط علوي أنيق يتضمن اسم التطبيق أو تحية للمستخدم
- مربع بحث واضح
- Banner أو قسم مقالات مميزة
- تصنيفات علمية أفقية أو شبكية
- أقسام مثل:
  - الأحدث
  - الأكثر قراءة
  - مقالات مختارة لك
  - مقالات قصيرة
  - اكتشف اليوم
- بطاقات مقالات احترافية
5. Categories Screen
- عرض مجالات العلوم كبطاقات أو أيقونات جذابة
- كل مجال له طابع بصري خفيف خاص دون كسر الهوية العامة
- سهولة الانتقال بين المجالات
6. Article Listing Screen
- قائمة أو شبكة مقالات
- فلترة حسب المجال أو مدة القراءة أو المستوى
- تصميم نظيف جدًا
- إظهار صورة مصغرة، عنوان، وصف قصير، وقت القراءة، ووسم المجال
7. Article Detail / Reading Screen
- أهم شاشة في المشروع
- واجهة قراءة فاخرة جدًا ومريحة
- عنوان المقال واضح
- اسم الكاتب أو المصدر
- تاريخ النشر
- وقت القراءة
- أزرار: حفظ، مشاركة، تكبير الخط، الوضع الليلي، العودة
- تنسيق محتوى منظم بعناوين فرعية وصور أو رسوم توضيحية عند الحاجة
- شريط تقدم للقراءة أو مؤشر موضع داخل المقال
- قسم "مقالات مشابهة"
8. Search Screen
- بحث ذكي وبسيط
- اقتراحات بحث
- كلمات مفتاحية رائجة
- عرض نتائج منظم ومقروء
9. Saved Articles Screen
- عرض المقالات المحفوظة
- تصميم واضح يسمح بالعودة السريعة للمحتوى
10. Notifications Screen
- إشعارات متعلقة بمقالات جديدة أو مجالات يتابعها المستخدم
- تصميم مرتب وغير مزعج
11. Profile Screen
- معلومات المستخدم
- الاهتمامات العلمية
- سجل القراءة
- المقالات المحفوظة
- الإعدادات
- الوضع الليلي
- اللغة
- إدارة التنبيهات
12. Bottom Navigation Bar
- الرئيسية
- التصنيفات
- البحث
- المحفوظات
- الحساب
عناصر UX الأساسية:
- سهولة التنقل
- وضوح بصري عالٍ
- تركيز كبير على راحة القراءة
- تقليل التشتيت
- إبراز المقالات المهمة دون ازدحام
- تجربة استخدام قريبة من أفضل تطبيقات المحتوى العالمية لكن بروح عربية علمية واضحة
عناصر إضافية مرغوبة:
- شارة "موثوق"
- شارة "الأكثر قراءة"
- شارة "جديد"
- شريط تقدم يومي للقراءة
- توصيات ذكية
- قسم "تابع اهتماماتك"
- إمكانية حفظ المقال للقراءة لاحقًا
- إمكانية تخصيص التخصصات المفضلة
المطلوب النهائي من الإخراج:
- إنشاء لوحة عرض متكاملة لتصميم التطبيق
- عرض الشاشات الرئيسية كلها بأسلوب موحد
- تقديم تصميم عالي الدقة High-Fidelity
- إبراز نظام الألوان والخطوط والأزرار والبطاقات والأيقونات
- إظهار حالات متعددة للعناصر مثل:
  - normal
  - active
  - selected
  - saved
  - dark mode
- تصميم يبدو جاهزًا للعرض على مستثمر أو فريق تطوير حقيقي
تعليمات صارمة:
- لا تنتج تصميمًا عامًا أو طفوليًا أو مزدحمًا
- لا تجعل التطبيق شبيهًا بتطبيق أخبار عادي
- يجب أن يبدو كتطبيق علمي فاخر ومعرفي
- لا تكثر الزخرفة
- الأولوية للثقة، الوضوح، وسهولة القراءة
- اجعل التصميم مناسبًا فعلًا للاستخدام اليومي الطويل
- حافظ على توازن ممتاز بين الجمال والعملية
- اجعل اسم التطبيق "علومكم" ظاهرًا بوضوح في الهوية
- ضمّن اسم المشروع الداخلي kamel3lom داخل البناء الإبداعي للمخرجات
- أخرج النتيجة في شكل واجهات تطبيق حقيقية، وليس مجرد شرح نصي أو وصف نظري
