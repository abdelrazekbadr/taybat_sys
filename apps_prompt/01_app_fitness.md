المطلوب:
إنشاء تصميم واجهة تطبيق جوّال احترافي متكامل لتطبيق عربي باسم "[اسم التطبيق]"، متخصص في اللياقة البدنية أو الصحة الرقمية، مع تجربة استخدام ممتازة، ونظام تصميم واضح، وشاشات مترابطة قابلة للتحويل إلى نموذج أولي عالي الدقة.

فكرة التطبيق:
التطبيق هو منصة ذكية تساعد المستخدم على تحسين صحته أو لياقته من خلال:

- تتبع النشاط اليومي
- متابعة التمارين الرياضية
- تنظيم الخطط التدريبية
- متابعة التغذية والسعرات
- تتبع النوم والماء والوزن
- مراقبة مؤشرات صحية أساسية
- التحفيز المستمر عبر الأهداف والإنجازات والتحديات

يمكن توجيه التطبيق بأحد المسارين:

1. Fitness Mode:
   يركز على التمارين، الأداء، الخطط الرياضية، حرق السعرات، وبناء العادات الرياضية.
2. Health Mode:
   يركز على المؤشرات الصحية، نمط الحياة، النوم، التغذية، الترطيب، الوزن، والتنبيهات الصحية.

الجمهور المستهدف:

- الشباب والبالغون
- المبتدئون في الرياضة
- الأشخاص المهتمون بالصحة اليومية
- المستخدمون الراغبون في تحسين نمط حياتهم
- فئة عمرية واسعة من 16 سنة فما فوق

الهدف من التطبيق:

- تسهيل متابعة الصحة أو اللياقة في واجهة واضحة وسلسة
- تشجيع المستخدم على الاستمرار اليومي
- تحويل البيانات اليومية إلى تجربة مفهومة ومحفزة
- بناء الثقة من خلال واجهة هادئة واحترافية
- تقليل التعقيد وجعل المتابعة الصحية أو الرياضية ممتعة

الهوية البصرية المطلوبة:

- أسلوب بصري حديث جدًا
- احترافي، فاخر، هادئ، ونظيف
- يوازن بين النشاط والطمأنينة
- مناسب للاستخدام اليومي الطويل
- لا يكون طفوليًا ولا مزدحمًا

لوحة الألوان المقترحة:

- إذا كان التطبيق أقرب إلى اللياقة:
  Emerald Green / Electric Blue / Deep Navy / White / Soft Gray
- إذا كان أقرب إلى الصحة:
  Calm Teal / Medical Blue / Soft White / Light Gray / Dark Text
- يمكن دعم الوضع الليلي بشكل متكامل
- استخدم ألوانًا ثانوية لإبراز الإنجازات والتنبيهات والتقدم

اللغة والاتجاه:

- اللغة الأساسية: العربية
- اتجاه التصميم: RTL
- مع قابلية لاحقة لدعم الإنجليزية
- العناوين واضحة جدًا
- النصوص مختصرة، هادئة، ومحفزة
- يجب مراعاة سهولة القراءة وعدم ازدحام الواجهة

الخطوط:

- استخدم خطوطًا عربية حديثة وواضحة
- اجعل العناوين قوية
- اجعل الأرقام والمؤشرات بارزة بصريًا
- حافظ على Hierarchy بصري ممتاز بين العنوان، القيمة، الوصف، وأزرار التفاعل

الشاشات المطلوبة بالتفصيل:

1. Splash Screen

- عرض اسم التطبيق أو الشعار بشكل قوي وهادئ
- انطباع أول احترافي وصحي
- لمسة بصرية توحي بالنشاط أو العافية

2. Onboarding Screens

- 3 شاشات تعريفية
- إبراز سهولة الاستخدام
- إبراز تتبع التقدم
- إبراز التخصيص حسب الهدف
- إبراز التحفيز والاستمرارية

3. Sign In / Sign Up

- تسجيل دخول بسيط جدًا
- دعم الهاتف أو البريد الإلكتروني
- واجهة نظيفة وسريعة

4. Home Dashboard

- أهم شاشة في التطبيق
- عرض ملخص اليوم بشكل أنيق
- بطاقات مثل:
- عدد الخطوات
- السعرات المحروقة
- دقائق النشاط
- شرب الماء
- النوم
- الوزن أو النبض عند الحاجة
- قسم الهدف اليومي
- قسم التقدم الأسبوعي
- قسم التوصيات أو التنبيهات الذكية

5. Goals Screen

- تحديد أهداف مثل:
- خسارة الوزن
- زيادة النشاط
- تحسين النوم
- شرب الماء
- بناء العضلات
- تحسين اللياقة العامة
- واجهة سهلة لتخصيص الهدف والخطة

6. Activity / Workout Screen

- عرض التمارين أو الأنشطة اليومية
- تقسيم البرامج حسب المستوى
- إبراز مدة التمرين، شدته، والسعرات التقديرية
- زر واضح لبدء التمرين

7. Workout Detail / Plan Detail Screen

- صورة أو رسم توضيحي للتمرين
- اسم التمرين أو الخطة
- المدة
- المستوى
- الأدوات المطلوبة
- الوصف
- الخطوات
- زر بدء
- زر حفظ
- شريط تقدم أو عدد الجولات

8. Nutrition / Meal Screen

- عرض الوجبات أو الخطة الغذائية
- حساب السعرات
- تقسيم البروتين، الكربوهيدرات، الدهون
- تسجيل الوجبات بسهولة
- واجهة واضحة وغير معقدة

9. Health Metrics Screen

- تتبع مؤشرات مثل:
- الماء
- النوم
- الوزن
- النبض
- الضغط أو السكر عند الحاجة في النسخ الصحية
- بطاقات أو رسوم بيانية سهلة القراءة
- إدخال يدوي أو تزامن مع الأجهزة عند الحاجة بصريًا

10. Progress / Statistics Screen

- رسوم بيانية أنيقة
- عرض التغير اليومي والأسبوعي والشهري
- إبراز الإنجازات
- مقارنة بين الهدف والنتيجة
- واجهة قوية بصريًا دون تعقيد

11. Challenges / Motivation Screen

- تحديات يومية أو أسبوعية
- شارات الإنجاز
- رسائل تحفيزية
- نظام Gamification خفيف وراقي

12. Subscription / Plans Screen

- عرض الباقات
- إبراز الفرق بين المجاني والمدفوع
- تصميم واضح ومقنع دون مبالغة
- CTA واضح للاشتراك

13. Notifications Screen

- تنبيهات صحية أو رياضية
- تذكير بالماء
- تذكير بالنشاط
- تحديثات الإنجاز
- تصميم مرتب وواضح

14. Profile Screen

- معلومات المستخدم
- الأهداف
- بيانات الجسم أو الحالة الصحية الأساسية
- الإعدادات
- اللغة
- التنبيهات
- الوضع الليلي
- الربط مع الأجهزة
- إدارة الاشتراك

15. Bottom Navigation Bar

- الرئيسية
- النشاط أو التمارين
- الإحصاءات
- التحديات أو التغذية
- الحساب

عناصر UX الأساسية:

- تقليل الخطوات
- وضوح البيانات
- إبراز التقدم اليومي
- تحفيز المستخدم دون ضغط بصري
- سهولة إدخال البيانات
- سهولة التنقل بيد واحدة
- جعل التطبيق مريحًا ومتكرر الاستخدام يوميًا

عناصر إضافية مرغوبة:

- شارة “أنجزت اليوم”
- شارة “هدف مكتمل”
- شارة “ممتاز”
- حلقات تقدم دائرية
- بطاقات ذكية للتوصيات
- قسم “استمر”
- قسم “ملخص الأسبوع”
- دعم الوضع الليلي
- حالات العناصر:
  normal
  active
  selected
  completed
  disabled
  loading

المطلوب النهائي من الإخراج:

- إنشاء لوحة عرض متكاملة لتصميم التطبيق
- عرض الشاشات الرئيسية كلها بأسلوب موحد
- تقديم تصميم High-Fidelity
- إبراز نظام الألوان والخطوط والأزرار والبطاقات والأيقونات
- إظهار حالات الاستخدام المختلفة
- تصميم يبدو جاهزًا للعرض على مستثمر أو فريق تطوير حقيقي
- مظهر واقعي جدًا وليس مجرد Mockup عام أو سطحي

تعليمات صارمة:

- لا تنتج تصميمًا طبيًا جامدًا جدًا إلا إذا كان التطبيق صحيًا سريريًا بحتًا
- لا تنتج تصميمًا رياضيًا صاخبًا أو طفوليًا
- يجب أن يبدو التطبيق حديثًا، احترافيًا، هادئًا، ومحفزًا
- الأولوية للوضوح، الثقة، وسهولة الاستخدام
- اجعل الأرقام والمؤشرات مفهومة بصريًا بسرعة
- اجعل الهوية البصرية قوية وقابلة للتوسع
- اجعل اسم التطبيق ظاهرًا بوضوح
- ضمّن اسم المشروع الداخلي داخل البناء الإبداعي للمخرجات
- أخرج النتيجة في شكل واجهات تطبيق حقيقية، وليس مجرد شرح نصي أو وصف نظري
