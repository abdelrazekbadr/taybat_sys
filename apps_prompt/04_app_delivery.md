المطلوب:
إنشاء تصميم واجهة تطبيق جوّال احترافي متكامل لتطبيق توصيل عربي باسم "[اسم التطبيق]"، متخصص في توصيل الطلبات بسرعة وكفاءة، مع تجربة استخدام ممتازة، ونظام تصميم واضح، وشاشات مترابطة قابلة للتحويل إلى نموذج أولي عالي الدقة.
فكرة التطبيق:
التطبيق هو منصة توصيل ذكية وسريعة تتيح للمستخدم:
- طلب الطعام من المطاعم
- شراء مستلزمات البقالة
- طلب منتجات الصيدلية
- توصيل الطرود الخفيفة
- الوصول إلى المتاجر والخدمات اليومية القريبة
الجمهور المستهدف:
- المستخدمون اليوميون في المدن
- الأسر
- الموظفون
- الطلاب
- من يفضّلون السرعة والراحة
- الفئة العمرية من 16 سنة فما فوق
الهدف من التطبيق:
- تسهيل عملية الطلب بأقل عدد ممكن من الخطوات
- تقديم تجربة استخدام سريعة وواضحة
- بناء الثقة عبر عرض الأسعار والوقت والتقييمات بشفافية
- تشجيع المستخدم على تكرار الطلب والعودة اليومية للتطبيق
- تقليل التشتت ورفع معدل إتمام الطلب
الهوية البصرية المطلوبة:
- أسلوب بصري حديث جدًا
- احترافي، فاخر، سريع، ومريح للعين
- غير مزدحم
- يركز على الوضوح والثقة والسرعة
- مناسب للاستخدام اليومي الطويل
لوحة الألوان المقترحة:
- لون أساسي قوي يعبّر عن السرعة والثقة مثل:
  Deep Orange أو Bold Red أو Premium Green بحسب هوية العلامة
- ألوان مساندة:
  White
  Soft Gray
  Charcoal / Dark Text
  Light Beige أو Off-White للخلفيات
- يمكن دعم الوضع الليلي بشكل متكامل
اللغة والاتجاه:
- اللغة الأساسية: العربية
- اتجاه التصميم: RTL
- مع قابلية لاحقة لدعم الإنجليزية
- يجب أن تكون العناوين واضحة جدًا
- النصوص قصيرة ومباشرة ومناسبة لتطبيق خدمات سريع
الخطوط:
- استخدم خطوطًا عربية حديثة وواضحة
- اجعل العناوين قوية
- اجعل الأسعار، أوقات التوصيل، وأزرار الطلب بارزة بصريًا
- حافظ على Hierarchy بصري ممتاز بين العنوان والوصف والسعر والعناصر التفاعلية
الشاشات المطلوبة بالتفصيل:
1. Splash Screen
- عرض اسم التطبيق أو الشعار بشكل قوي
- انطباع أول احترافي وسريع
- لمسة بصرية توحي بالخدمة الفورية والثقة
2. Onboarding Screens
- 3 شاشات تعريفية
- إبراز السرعة
- سهولة الطلب
- تنوع الخدمات
- تتبع الطلب لحظة بلحظة
3. Sign In / Sign Up
- تسجيل دخول بسيط جدًا
- دعم الهاتف أو البريد الإلكتروني
- واجهة نظيفة وسريعة
4. Home Screen
- شريط علوي يتضمن الموقع الحالي
- مربع بحث بارز
- بانر عروض أو خصومات
- تصنيفات الخدمة: مطاعم، بقالة، صيدلية، طرود، وغيرها
- أقسام مثل:
  - الأقرب إليك
  - الأعلى تقييمًا
  - الأسرع توصيلًا
  - العروض الحصرية
  - طلبات متكررة
- بطاقات متاجر واضحة واحترافية
5. Categories Screen
- عرض الخدمات أو الفئات بشكل بصري جذاب
- أيقونات حديثة
- سهولة التنقل بين أنواع التوصيل المختلفة
6. Store Listing Screen
- قائمة المتاجر أو المطاعم
- إظهار:
  - صورة الغلاف
  - الاسم
  - التقييم
  - زمن التوصيل
  - رسوم التوصيل
  - الحد الأدنى للطلب
  - الوسوم مثل: سريع، خصم، الأكثر طلبًا
7. Store Detail Screen
- غلاف بصري احترافي
- وصف مختصر
- الأقسام الداخلية
- المنتجات أو الوجبات
- زر طلب واضح
- تقييمات العملاء
- عروض المتجر
8. Product Detail Screen
- صورة المنتج
- الاسم
- السعر
- الوصف
- الإضافات أو الخيارات
- ملاحظات الطلب
- اختيار الكمية
- زر إضافة إلى السلة
9. Cart Screen
- عرض المنتجات المختارة
- تعديل الكمية
- حذف العناصر
- ملخص السعر
- رسوم التوصيل
- الخصم
- الإجمالي النهائي
- زر متابعة الطلب
10. Address Selection Screen
- اختيار العنوان من الخريطة أو العناوين المحفوظة
- تحديد الموقع بدقة
- إضافة وصف للمبنى أو الشقة
- تصميم واضح جدًا
11. Checkout / Payment Screen
- اختيار طريقة الدفع
- بطاقة / نقدًا / محفظة / Apple Pay / مدى / غيرها بصريًا
- ملخص الطلب النهائي
- كود خصم
- تأكيد الطلب
12. Order Tracking Screen
- أهم شاشة بعد الدفع
- خريطة حديثة وأنيقة
- حالة الطلب خطوة بخطوة:
  تم الاستلام
  جاري التحضير
  خرج مع المندوب
  اقترب من الموقع
  تم التسليم
- بطاقة للمندوب مع الاسم، الصورة، التقييم، وسيلة التواصل
- عداد زمني تقديري للوصول
13. Offers Screen
- العروض والخصومات
- قسائم الشراء
- واجهة جذابة وغير مزدحمة
14. Orders History Screen
- الطلبات السابقة
- إعادة الطلب بسرعة
- حالة كل طلب
- تقييم الطلب السابق
15. Notifications Screen
- إشعارات الطلبات
- العروض
- تحديثات الحساب
- تصميم مرتب وواضح
16. Profile Screen
- معلومات المستخدم
- العناوين المحفوظة
- وسائل الدفع
- الطلبات السابقة
- المفضلة
- الإعدادات
- اللغة
- التنبيهات
- الدعم الفني
17. Bottom Navigation Bar
- الرئيسية
- التصنيفات
- الطلبات
- العروض
- الحساب
عناصر UX الأساسية:
- أقل عدد ممكن من الخطوات لإتمام الطلب
- وضوح شديد في الأسعار والوقت
- إبراز زر الإجراء الرئيسي CTA
- تقليل التشتيت
- سهولة البحث والوصول
- تجربة سريعة جدًا من الصفحة الرئيسية حتى إتمام الطلب
- واجهة مناسبة للاستخدام بيد واحدة على الجوال
عناصر إضافية مرغوبة:
- شارة “خصم”
- شارة “الأسرع”
- شارة “الأكثر طلبًا”
- شارة “موصى به”
- نظام تقييم واضح
- اقتراحات ذكية حسب الطلبات السابقة
- قسم “أعد طلبه”
- قسم “قريب منك”
- دعم الوضع الليلي
- حالات العناصر:
  normal
  active
  selected
  disabled
  loading
  delivered
المطلوب النهائي من الإخراج:
- إنشاء لوحة عرض متكاملة لتصميم التطبيق
- عرض الشاشات الرئيسية كلها بأسلوب موحد
- تقديم تصميم High-Fidelity
- إبراز نظام الألوان والخطوط والأزرار والبطاقات والأيقونات
- إظهار حالات الاستخدام المختلفة
- تصميم يبدو جاهزًا للعرض على مستثمر أو فريق تطوير حقيقي
- مظهر واقعي جدًا وليس مجرد Mockup عام أو سطحي
تعليمات صارمة:
- لا تنتج تصميمًا طفوليًا أو عامًا أو مزدحمًا
- لا تجعل التطبيق مجرد نسخة رخيصة من تطبيقات التوصيل المعروفة
- يجب أن يبدو التطبيق حديثًا، احترافيًا، وسريعًا
- الأولوية للوضوح وسهولة الاستخدام والتحويل إلى طلب فعلي
- اجعل تجربة الطلب قصيرة ومباشرة
- اجعل عناصر السعر والتوصيل والتتبع واضحة جدًا
- اجعل الهوية البصرية قوية وقابلة للتوسع
