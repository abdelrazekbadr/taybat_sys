# Tayyibat App - Phase 1 (MVP Detailed)

## 🎯 Overview

Phase 1 is built on:
👉 **Compliance First (الالتزام أولًا)**

هدف المرحلة:

- تقليل التعقيد
- بناء الالتزام
- تقديم تجربة سهلة وسريعة

# ⚙️ Core Features

## 1. Food Repository

قاعدة بيانات لكل الأطعمة:

- مصنفة
- تحتوي صور
- مسموح / ممنوع

---

## 2. Food Availability Setup

### الفكرة:

المستخدم يحدد:
👉 “ما المتوفر عندي”

### UX:

- Tap فقط
- بدون كتابة
- صور للأطعمة

---

## 3. Weekly Plan (جدول أسبوعي)

### الخصائص:

- يتم توليده تلقائيًا
- مبني على المتاح
- يحتوي صور
- بسيط جدًا

### زر:

🔄 تغيير الأسبوع

---

## 4. Daily Flow

1. هل أنت جائع؟
2. اقتراح وجبة
3. تنفيذ
4. تسجيل الالتزام

---

## 5. Smart Reminder

- هل أنت جائع؟
- هل التزمت اليوم؟

---

## 6. Compliance System (نظام الالتزام)

- المستخدم يحدد:
  - هل التزم؟
- يتم حساب:
  - نسبة الالتزام
  - Streak

---

## 7. Locked Progress (نظام القفل)

⚠️ أهم ميزة

إذا الالتزام < 70%

❌ يتم إخفاء:

- النتائج
- التقدم

---

## 8. Unlock System

- 3 أيام التزام → فتح التتبع
- 7 أيام → فتح التحليل
