## القواعد الأساسية
## Basic Rules

| القاعدة | Rule |
|--------|------|
| كل الأطعمة من المسموح فقط | Only eat from the allowed foods |
| بدون بروتين حيواني اختياري | No optional animal protein |
| بدون دهن أبيض | No white fat |
| شرب الماء يومياً | Drink water daily |
| صيام منقطع | Intermittent fasting |
| مناسب للتنحيس والصحة العامة | Suitable for weight loss and general health |
