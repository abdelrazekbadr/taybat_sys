## القواعد الواجب الالتزام بها
## Rules to Follow

### 🍽️ القواعد الذهبية الست | Six Golden Rules

1. **لا تأكل إلا عند الجوع** - تحسّس الجوع الحقيقي فقط
2. **لا تأكل حتى الشبع** - توقف قبل الامتلاء بخطوة واحدة
3. **الصيام الأسبوعي والشهري** - الاثنين والخميس + أيام البيض (13-14-15)
4. **الخل الطبيعي يومياً** - كوب ماء مع الخل بعد الوجبات
5. **الماء الدافئ على الريق** - قبل أي شيء صباحاً
6. **رياضة يومية خفيفة** - مشي أو تمارين بسيطة
