**Method 1: Gmail/Google OAuth**
```
Flow: Tap "Sign Up with Google"
  → Google Consent Screen
  → Supabase OAuth Handler
  → Account Created
  → Complete Profile Screen
  → Meal Preferences
  → Main App
```

**Method 2: Facebook OAuth**
```

```

**Method 3: Apple OAuth**

**Method 4: Custom Email/Password**
```
Flow: Tap "Create Account"
  → Enter Email & Password
  → Validation (Zod Schema)
  → Supabase Auth.signUp()
  → Account Created
  → Complete Profile Screen
  → ... (same as OAuth)
```
