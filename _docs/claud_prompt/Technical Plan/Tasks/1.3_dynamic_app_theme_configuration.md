# TASK 1.3: Dynamic App Theme Configuration

## TASK 1.3: Dynamic App Theme Configuration
**Priority**: 3  
**Time Estimate**: 3 hours  
**Status**: Completed

### Description
Implement a centralized, dynamic theming system (Light/Dark/System) aligned with Al‑Tayebat brand tokens and ready to be consumed by UI components, navigation, and screens.

### Business Scenarios Covered
- ✅ App uses consistent brand colors/typography across all screens
- ✅ Dark mode is supported (Auto / Light / Dark)
- ✅ RTL-ready theme settings (Arabic-first UX)
- ✅ Theme can be switched at runtime without restart
- ✅ Theme choice can be persisted for next launch

### AI Agent Prompt

```
TASK: Implement Dynamic Theme Configuration for React Native

CONTEXT:
- App name: "Al‑Tayebat" (Arabic RTL-first)
- UI library: react-native-paper

REQUIREMENTS:
1. Create theme module under src/theme/:
   - tokens: colors, typography, spacing, radius, elevation
   - light + dark theme objects
   - a single exported function to build the active theme

2. Brand tokens (from design prompt):
   - Primary Emerald: #10B981 (alt: #059669)
   - Accent Teal: #06B6D4 (alt: #0891B2)
   - Deep Navy: #1e293b
   - Background Light: #ffffff / #f1f5f9
   - Dark Mode: bg #0f172a, cards #1e293b, text #f1f5f9
   - Secondary accents: Gold #f59e0b, Orange #fb923c, Rose #fb7185, Purple #a78bfa

3. Add a theme preference model:
   - mode: 'system' | 'light' | 'dark'
   - default to 'system'
   - persist mode (AsyncStorage)

4. Integrate with providers:
   - react-native-paper: PaperProvider uses the active theme
   - react-navigation: map theme colors (background/card/text/primary) to navigation theme
   - use system color scheme when mode === 'system'

5. Typography:
   - define a hierarchy (H1/H2/H3/Body/Caption/Metrics) and attach to theme
   - support Arabic-friendly fonts (Cairo/Tajawal) via theme configuration (actual font install can be separate)

6. Non-functional requirements:
   - do not hardcode colors in screens; consume from theme
   - ensure contrast is acceptable in dark mode
   - keep exports clean (barrel export via src/theme/index.ts)

OUTPUT:
- Central theme module with light/dark/system support
- Theme persisted and restored on launch
- Providers wired so screens can use theme consistently
```

  background: '#0f172a',

  accentTeal: '#06d6ff',
  accentEmerald: '#10d981',

// src/theme/theme.ts
export type ThemeMode = 'system' | 'light' | 'dark';

export function buildTheme(params: { mode: ThemeMode; systemIsDark: boolean }) {
  const isDark = params.mode === 'dark' || (params.mode === 'system' && params.systemIsDark);
  return isDark ? darkTheme : lightTheme;
}

// src/theme/index.ts
export * from './theme';
